# Changelog

## 1.0.0 — 2026-10-26

Initial public release of Adaptive Codex Orchestrator.

- Instruction-only skill with seven references covering coordination, ownership, context, verification, and recovery.
- Optional Codex configuration examples, including an explicitly selected Terra worker profile.
- Self-contained research report and original evidence from six development smoke trials.
- Four deterministic coding fixtures, a local grader, and twelve evaluator unit tests.
- Public installation and compatibility guides, a non-overwriting installer, and installer tests.
- Package checksums, automated checks, and a hosted report through GitHub Pages.

The original skill and report are preserved from the supplied v1 package. Public packaging and documentation were added for this release. Comparative speed, cost, and production reliability remain unmeasured.
