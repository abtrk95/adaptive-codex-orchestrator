# Examples

These are task applications, not mandatory scripts or measured performance predictions.

## Tiny fix

`$adaptive-codex-orchestrator Fix the off-by-one error in this range helper and verify its boundary case.`

Inspect the narrow path, change it directly, and run a meaningful check. No ledger or extra agent is required unless a material complication emerges.

## Multi-module feature

`$adaptive-codex-orchestrator Add CSV and JSON imports using native Terra 6.1 workers where useful. Preserve the public API and verify end-to-end imports.`

Own the shared contract/registry centrally. If substantial adapters are independent, delegate their disjoint implementations/tests. Integrate serially and test real registry-to-adapter behavior. Stabilize changing interfaces before parallel writes.

## Unfamiliar codebase and intermittent bug

`$adaptive-codex-orchestrator Investigate intermittent duplicate jobs. Preserve existing changes and distinguish a reproduced fix from a hypothesis.`

Map scheduler/tests, optionally split read-only investigations of retry idempotence and concurrent claiming, and avoid shared queue/test interference. Use a controlled reproducer to discriminate. Verify the smallest supported fix and disclose nonreproduced behavior.

## Refactor

`$adaptive-codex-orchestrator Consolidate duplicate validation while preserving behavior and callers. Parallelize only at safe module boundaries.`

Establish existing behavior/edits, give the shared API one owner, and move callers only against a stable contract. Keep integration/dependency updates serial; use relevant regression/differential checks. Do not split coupled work to fill slots.

## Conflicting findings

Compare input/revision evidence for a cache hypothesis and a parsing hypothesis, then use the actual call path or a discriminating test. Both may be true. Do not vote; preserve unresolved impact.

## Failed writer

Observe the native turn and known command sessions, preserve partial edits, and establish termination before assigning its files again. If unknown, continue nonconflicting work and mark the paths blocked. An accepted interrupt is insufficient.

## Strict limits

`$adaptive-codex-orchestrator Complete this change using at most one native worker. Do not substitute another model for Terra 6.1.`

Honor the cap. If Terra selection fails, continue useful coordinator work and disclose that no substitute ran. Reserve required verification time and report any unresolved criterion.
